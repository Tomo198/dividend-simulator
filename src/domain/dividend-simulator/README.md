# Calculation domain

`docs/product-spec.md` のフェーズ1計算仕様をこのディレクトリに実装しています。

- React、DOM、ブラウザAPIへ依存しない純粋関数を基本とする。
- 割合は内部で0〜1として保持し、計算中は表示用の丸めを行わない。
- 税、コスト、成長、購入、月次シミュレーション、集約、目標逆算、XIRRを責務ごとに分ける。
- UIはこのドメインが返す結果だけを表示し、計算式を複製しない。
- 比較機能は単一銘柄エンジンを再利用し、比較専用の計算式を持たない。

固定fixtureを使う単体・統合テストは `__tests__/` に置き、税、購入、成長、分配スケジュール、月次計算、目標逆算、XIRRを検証します。比較専用ロジックとUIはこのフェーズには含めません。
